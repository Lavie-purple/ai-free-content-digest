## 展示规则
- **目录「头条」只写当天发生的新闻事件（2026-11-06 用户「以后都不要这样」）**：
  `archive.html` 列表 / 最新一期大卡片 / `INDEX.md` 主题列的唯一真源是 `.workbuddy/data/headlines.json`，
  每期一条「谁发布/免费了什么、额度、截止」。**禁止**把「本报告改进了什么 / 纠错 / 挂账 / 补登 /
  口径 / 轮次 / 方法论 / 至今第一次读到」当头条 —— 那些照旧写进正文给读者，只是**不占头条位**。
  每出一期**必须往台账加一行**；`check_headlines.py` 已挂 `build_site.sh`，
  缺行或写回元叙述即 `exit 1`（⚠️ 该守卫不能加管道，`set -e` 下 `| tail` 会吞掉退出码）。
  两个索引脚本 `theme_of(text, no)` 台账优先、刊头定位语只作兜底；列表截断放宽到 `72` 字，
  大卡片 `80` 字，避免短标题再被截成「…」。
- **完整日报网页层 = 30 秒卡 + 审计层折叠（060 期 A 方案）**：`build_web.py` 自动加速览卡（头条取 `headlines.json`、数字从表体实算），`s04/s05/s06/s08/s09` 五章默认收进 `<details>`；**信息一条不删，逐 section 与改前逐字一致**。
  **md 章节编号不能变**（`FOLD_SECTIONS` 靠 `sNN` 认人）。折叠会打断搜索命中 / 目录跳转 / 打印 / `.rise` 动画 / `syncMetrics` 量高，五件都已在 JS 补做；`PAGE` 是普通字符串，CSS/JS 反斜杠写双份。
- **`AI信息源分级清单-T0-T4.md` 不对外展示**（内部台账，只用于路由与去重），照旧就地维护。
- 每次出刊**只 `present_files` 那一份日报**；**只有用户明确要求才展示台账**。
- **用户问「最简版 / 只看免费」时给 `quick.html`**（不是日报）：那条线只答四个字段。
- **站点首页 = 极速视图（2026-11-02 用户要求「以后每天运行都把极速视图作为首页」）**：
  `index.html` 由 `build_quick.py` **与 `quick.html` 同字节写两份**（不是「首页第一张卡是极速」，
  是**同一份内容**）；往期总目录搬到 `archive.html`（`build_index_web.py`），从极速页页头右上
  「往期总目录」与页脚「历史各期索引」进入。**守卫：`check_views.py` 断言 `index.html == quick.html`
  字节相等 + 首页当前格必须是 quick**；`check_site_freshness.py` 断言极速「本页基准日」= 最新一期日期。
  **⚠️ 页面里不许再出现 `href="index.html"`**（会自指打转）—— `build_quick.py` 出口处直接 `exit 1`。
- **三页是「一份刊物的三个视图」**：日报 / `quick.html` / `standing.html` 顶部同一位置都有三格切换器
  （极速 / 完整 / 总账，当前格实心 + `aria-current`）；`archive.html`（往期总目录）三格**都不高亮**。
  组件在 `viewswitch.py` —— **改一处、五页同时变**；**条数一律实算**。
- **「同构」由 `check_views.py` 守**（每期必跑 · 五页）：三格齐全、当前格唯一、「完整日报」指向最新一期、
  格内条数与源文件实算一致、首页与极速同字节；**任何一处不符 exit 1**。
- **极速页顶部不许用「三格数字框」**（2026-11-06 用户「不要这样框法」）：切换器下方只留**一行无框概览句** `<p class="pulse">`（主读数在前、两条附注随后，零边框零底色）；数字仍由 `build_quick.py` 实算 `n_live/n_week/n_over`，**改版式不许改数字来源**。日报的 30 秒卡是另一套，未动。
- **极速页首屏不放口径说明块**（2026-11-06 用户：「本页不收什么这段其实不用显示给用户看」）：该段已从首屏移除、内容整合进页脚「要追证」；导语 `.lede` 不许再加 `max-width` 窄栏限制，须与下方表格同宽。
- **常驻总账页：目录默认折叠、全量表按 `28/32/40%` 配宽**（2026-11-06 用户）：目录收成主区顶部一行 `<details class="toc-fold">`（默认收起、条目零删），`.shell shell-wide` 单列铺满，表加 `ledger-full` 类。**日报 4.1 的 `date=76px` 不许套到总账**（短日历日口径，会把中文压成竖排）。
- **完整日报目录 = 方案 A**（2026-11-07 用户选定）：显示序 `摘要 → 01 → 02 → 03 → 04 → 07 → 05 → 06 → 08 → 09`，四组标签「本期内容 / 马上要办 / 怎么用 / 审计层 · 默认折叠」（`TOC_ORDER` / `TOC_GROUPS`）；**正文物理顺序与章节编号一律不动**，点 04 跳到文末（`openFold` 自动展开）。排序分组**只许对 `is_digest` 生效** —— 附录 12 小节 aid 全是 `s-abs`，套上去会插 12 个「本期内容」标签。
- **可滚动表格的 sticky 表头不许有 `overflow:hidden`**（2026-11-07 修）：`.tbl` 上的 `overflow:hidden` 会新建滚动容器、废掉 `th{position:sticky}`；解药 `.tblwrap.scrolly .tbl{overflow:visible}`（**只加 `border-collapse:separate` 无效**，实测过）。改表格容器样式后量 `chips.bottom − th.top`，必须 = 0。
- **Pages 部署失败先查 `deployments` API，别猜缓存**（2026-11-07）：`pages/builds` 常 404，但 `/repos/<o>/<r>/deployments` + `/deployments/<id>/statuses` 能读到 sha 与 state；`state=failure` 且耗时≈10 分钟 = **Deploy 步骤超时**（服务端偶发）→ `git commit --allow-empty` 重试一次，**不改内容、不 force push**。只有 `Age` 近 600 且 `Last-Modified` 已刷新才是纯 CDN 缓存。
- **版面三件套（2026-11-07 用户两张截图）**：① 总账页底部不许留 `96px` 页脚上边距 ——
  `body.ledger-page .shell{padding-bottom:var(--s5)}`（40px），其它页照旧；② 日报目录行**不显示标题尾括号**，
  `_toc_label()` 剥掉 `（…）`、只留 `正文之后` 小标记，正文 `h2` 与附录目录（括号里是期次日期）不动；
  ③ 模板 `__DATELINE__` **必须被替换**（日报取「扫描截止」、总账取「最后全量复核」、没有就整段删），
  页脚左边用 `__ISSUE_LINE__` 而不是写死「第 N 期」，`<title>` 刊名页名相同则去重。
- **章节分组 / 折叠 / 排序一律认标题、不认编号**（2026-11-07 统一往期时修）：002–046 期第四章是
  「免费内容生成工具」、第五章才是限时表 —— 写死 `s04` 会标错「马上要办」、折错审计层、速览卡指错章。
  判据是 `kind_of()`（限时活动 / 选型速查 / 纠错·避坑·信源·核查），折叠、目录分组、顶栏 `tail`、
  速览卡章号全由它推导；047+ 各期输出逐字节不变。
- **五页重建一条命令**：`bash .workbuddy/build_site.sh`（日报 / 总账 / 附录 / 极速+首页 / 目录 + 三个守卫）。
- **出刊收尾三件套（每期必做，`build_site.sh` 不代劳）**：① 往 `data/headlines.json` 加本期一行纯事件标题（缺行守卫直接 `exit 1`）；
  ② `git add` 产物 → `commit` → `push`（仓库无 `.github/workflows`，**push 是触发 Pages 的唯一动作**，只构建不推 = 线上永远旧）；
  ③ 线上核对**先看 `Age`/`X-Cache`**：`max-age=600` 窗口内命中就是纯缓存、等窗口过、**不要重推**；
  超 15 分钟仍旧页再查 `/deployments` + `/statuses`（`failure` 且耗时≈10 分钟 = Deploy 超时，空提交重试一次）。
  **核对六页两个坑**：`curl --compressed` 与 `-H "Accept-Encoding: identity"` **同时用会返回 0 字节**（六页全假 `DIFF`）；期页 URL **照抄 `archive.html` 的 `href`**，多一个 `%20` 就拿到 9,379 字节的 `404` 页 —— **`DIFF` 先比响应体大小**。

## 出刊约定（全文见附卷 §十·22）
- **增量 + 纠错**，不重复往期已固化内容（先跑 `check_frozen.py`，🔴 高危 exit 1）。
- **十节固定结构**；**发布线与「免费内容」线是必备两章**。
- **刊头必标扫描截止时点**；**早间出刊必漏当天上午晚些时候的发布**。
- **同日双刊**：声明「正式刊 / 增补轮」+「两期不合并」+ 窗口起点 = 上期截止 + **美西/北京双向换算**；**隔日出刊换句式**。
- **短窗口（<2h）**：先核「窗口内确有落在线后的硬条目」再决定出刊/挂账。
- **「计数」与「明细」同源生成**；**禁用「状态变更共 N 处」**；台账写「（N→M）」当场用表体行数验。
- **继承字段必须重算**：断言是「每行天数 == 截止日 − 基准日」，**不是「推进一天就 −1」**。
  ⚠️ `extract_deadlines` **不解析状态列里的倒计时文本** → 必须逐行手算复核。
- **流通量字段不得沿用上期**，定稿前重取；**升/降/同值都要记账**；**口径变过不可相减**。
- **「降档」一次写全三样**（模型/上下文/额度）；**按四条线分别过**；**图像·视频模型线**与**内容平台榜单线**
  是固定扫描位；**「定编扫描位」当期写成两维关键词表并实跑**。
- **「开放」拆四层**（能用/能下载/能跑/能商用）；**多站点口径显式拆开写**（URL 主域名写进条目本身）。
- **第四章截止表一律脚本生成**（`gen_tableNNN.py` + `inject0NN.py`），**`<<<TABLE4>>>` 占位符必须为 0**。
- **第四章脚注固定四段**：① 三态分布 ② A/B/C/D/E 实跑 ②-补 双口径三态 ③ 逐行 diff + 强制动作；
  **⚪ 与 C 的差额不是常数** → **必须逐条归因**；**两套口径数字必须从 `deadlines.csv` 实跑**。
- **同仓库两种行尾**：`data/` CRLF、`memory/` LF。
