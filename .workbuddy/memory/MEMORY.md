## 出刊约定（全文见附卷 §十·22）
- **增量 + 纠错**，不重复往期已固化内容（先跑 `check_frozen.py`，🔴 高危 exit 1）。
- **十节固定结构**；**发布线与「免费内容」线是必备两章**。
- **刊头必标扫描截止时点**；**早间出刊必漏当天上午晚些时候的发布**。
- **同日双刊**：声明「正式刊 / 增补轮」+「两期不合并」+ 窗口起点 = 上期截止 + **美西/北京双向换算**；**隔日出刊换句式**。
- **短窗口（<2h）**：先核「窗口内确有落在线后的硬条目」再决定出刊/挂账 —— **只看窗口长度会误判**。
- **「计数」与「明细」同源生成**；**禁用「状态变更共 N 处」**；台账写「（N→M）」当场用表体行数验。
- **继承字段必须重算**：断言是「每行天数 == 截止日 − 基准日」，**不是「推进一天就 −1」**（040 期滚雪球）。
  ⚠️ `extract_deadlines` **不解析状态列里的倒计时文本** → 必须逐行手算复核。
- **流通量字段不得沿用上期**，定稿前重取；**升/降/同值都要记账**；**口径变过不可相减**。
- **「降档」一次写全三样**（模型/上下文/额度）；**按四条线分别过**；**图像·视频模型线**与**内容平台榜单线**
  是固定扫描位；**「定编扫描位」当期写成两维关键词表并实跑**。
- **「开放」拆四层**（能用/能下载/能跑/能商用）；**多站点口径显式拆开写**（URL 主域名写进条目本身）。
- **第四章截止表一律脚本生成**（`gen_tableNNN.py` + `inject0NN.py`），**`<<<TABLE4>>>` 占位符必须为 0**；
  **换挡日不写可被解析的实日期**。
- **第四章脚注固定四段**：① 三态分布 ② A/B/C/D/E 实跑 ②-补 双口径三态 ③ 逐行 diff + 强制动作；
  **⚪ 与 C 差 1 是正确口径**；**两套口径数字必须从 `deadlines.csv` 实跑**。
- **同仓库两种行尾**：`data/` CRLF、`memory/` LF。

## 出刊流水线（顺序固定）
1. 读上期 md + `data/frozen_items.md` + `data/open_questions.md`
2. `check_frozen.py`（🔴 高危 exit 1；**高危可能只是措辞触发，改措辞不改守卫**）
3. `extract_deadlines.py` → `check_deadlines.py --today YYYY-MM-DD`
4. 写 md（增量 + 纠错）；第四章用 `gen_tableNNN.py` + `inject0NN.py` 注入
5. `build_web.py` → `verify_web.py`（**必须 ALL GREEN**）
6. `build_source_hits.py` → `build_index.py` → `build_index_web.py` → `check_site_freshness.py`（后两个每期必跑）
7. git commit + push → **核实 sha** → 带 `?t=<ts>` 抓线上页**逐字节比对**
   （Pages 延迟 1–2 分钟；构建 API 无 token 返 404，逐字节比对可替代且更强）
   - ⚠️ push 报 `could not read Username`：`credential.helper=helper-selector` 坏 → `git-credential-manager get`
     令牌 + 内联助手推；别改 `helper=manager`（附卷 §九）。
   - ⚠️ **抓线上页前必须先确认构建完成**（011 期误判过）。
   - ⚠️ **`git add .workbuddy/data/` 会把 13 个历史备份一并暂存**，需逐条 `git reset`（不删，只是不进仓库）。
8. 写自动化记忆 + 当日日志
