## 出刊约定（短条目版 · 全文见 `ENGINEERING.md` §十·22）

- **增量 + 纠错**，不重复往期已固化内容（先跑 `check_frozen.py`，🔴 高危 exit 1）。
- **十节固定结构**，**发布线与「免费内容」线是必备两章，不能省**。
- **刊头必标扫描截止时点**；**早间出刊必漏当天上午晚些时候的发布**。
- **同日双刊**：显式声明「正式刊 / 同日第二轮（增补轮）」+「两期不合并、不互相覆盖」+ 窗口起点 = 上期截止 +
  **美西/北京双向换算**；**隔日出刊必须换句式**。
- **短窗口（<2h）**：先核「窗口内确有落在线后的硬条目」再决定出刊/挂账 —— **只看窗口长度会误判**。
- **「计数」与「明细」同源生成**；**禁用「状态变更共 N 处」**；台账写「（N→M）」当场用表体行数验。
- **继承字段必须重算**：断言是「每行天数 == 截止日 − 基准日」，**不是「推进一天就 −1」**（040 期实测滚雪球）。
  ⚠️ `extract_deadlines` **不解析状态列里的倒计时文本** → 必须逐行手算复核。
- **流通量字段（计数器/家数/名单条数）不得沿用上期**，定稿前必须重取；**升/降/同值三种结果都要记账**；
  **口径变过就不相减**（不得为凑数换不可比的新数字）。
- **「降档」一次写全三样**：模型 / 上下文 / 额度口径。
- **按四条线分别过**（模型/额度/产品/政策），**不按新闻条数过**；**图像·视频模型线**与**内容平台榜单线**是固定扫描位。
- **「定编扫描位」当期就写成两维交叉关键词表并当日实跑** —— **纪律停在文本层 = 没有纪律**。
- **「开放」拆四层**：能用吗 / 能下载吗 / 能跑吗 / 能商用吗。
- **多站点口径必须显式拆开写**（URL 主域名写进条目本身）。
- **第四章截止表一律脚本生成**（`gen_tableNNN.py` + `inject0NN.py`），**`<<<TABLE4>>>` 占位符必须为 0**；
  **换挡日不能写可被解析的实日期**。
- **第四章脚注固定四段并逐段打勾**：① 三态分布 ② A/B/C/D/E 实跑 ②-补 双口径三态 ③ 逐行 diff + 下一轮强制动作。
  **⚪ 与 C 差 1 是正确口径**；**两套口径数字与「差值 N 处」必须从 `deadlines.csv` 实跑**（预写必错）。
- **同仓库两种行尾**：`data/` CRLF、`memory/` LF。

## 042–043 期口径纪律索引（原文见 `ENGINEERING.md` §十·18–20）

> 042/043 两期的**避坑 183–192 原文、机制解释与逐条实测样本**已整体迁入 `ENGINEERING.md` §十·18（042 期五条实测样本）、
> §十·19（043 期五条实测样本）、**§十·20（042/043 两期「口径纪律」原文归位）**。本节只留索引式判据。

**042 期（2026-10-20）**
- **避坑 183**：同 URL 被改写后**错误转述不会自己停**，且复制品看起来完全正常 → **在 179「现场打开」外加判据「核对今天属于哪一档」**。
- **避坑 184**：跨组织事件**「谁承诺了什么」必须逐家抄**，动词即口径（承诺/正在进行/已启动/封禁不可互换），「未核到」不能写「不退款」。
- **避坑 185**：**安全护栏会按场景拒绝防守方** → 这类通道必须提前申请（事后申请流程上就来不及）。
- **避坑 186**：**套餐「模型名不变」可能是自动改路由** → 兼容层承诺不覆盖路由层事实。
- **避坑 187**：**「试点期结束后改为 X」条件里没日期就不算日期** → 记现状/变更后/生效时点是否确切，第三件缺则写「生效时点未公布」。
- **多站点口径三问**：① 规则属于哪个站点（**URL 主域名写进条目本身**）② 另一站点是否有独立规则页 ③「没有这条规则」的结论是在哪个站点得到的。
- **老模型下线的完整关停纪律 = 避坑 47（厂商不给日期）+ 避坑 164（给了日期怎么排）**，两条互补。

**043 期（2026-10-21）**
- **避坑 188**：**「开放权重」是四个状态**（① 已宣布 ② 官方承诺 ③ 给了具体日期 ④ 权重真在 HF 上），核验顺序 ①→④，**④ 之前一律按「只能 API 不能下载」规划**；第三方日期只能写「第三方口径」。
- **避坑 189**：**许可是五层**（① 下载闸门 ② 许可类型 ③ 地域范围 ④ 商业门槛 ⑤ 衍生义务），**后三层最常被漏**；**必须同时给反例**。
- **避坑 190**：**「防护提升 X%」必须连分母、范围、有效期一起读**，三句抄不到就写「未公布」，**不写「防护失效」也不写「防护有效」**。
- **避坑 191**：**限免「有多长」只认官方公告页**；**uptime 统计窗口（如「past 3 days」）不是限免期**；无官方截止日时第四章写「未公布」。
- **避坑 192**：**旧错误转述会从「全错」滑向「部分对」**（183 管「为什么持续」，192 管「为什么变淡」）→ **核活动规则要逐项核，总量自己用现行规则表求和**。
- **043 期新立两个条目类型**：**「框架开源」**（看能不能跑起来/依赖硬件/支持平台，**与权重开源的判据完全不同**）与**「开放权重四状态」**（避坑 188）。

**044 期（2026-10-22）**
- **避坑 193**：**「免费」至少三层** —— **开源自取 / 定向补贴 / 身份权益**；**三者获取成本完全不同，不可统称**（本期样本：`OpenAI` `Patch the Planet` 一篇公告里三层并存，官方逐字 `We’re sharing` / `$1 billion` 面向机构 / `Codex for OSS` 面向维护者需申请，**全页无 `free` 一词**）。
- **避坑 194**：**官方页面改 URL（加尾斜杠）时「抓到空页」极易被误读成「活动已撤」** → **判定活动是否还在必须看正文规则表**（本期样本：`autoclaw.z.ai/blog/news/M10W3` 返回 `301`、0 字节，`curl -sL` 跟随后正文正常）。
- **避坑 195**：**判断新产品「免费与否」有两条路** —— **「官方说免费」与「官方没说免费」**；**后者必须走完三步**（① 找免费字样 → ② 找权益归属 → ③ 找额度口径），**三步都无 = 官方无免费额度**（本期样本：`Anthropic` `Claude Duet`）。
- **044 期一条工程纪律**：**「同一实体的状态推进」是改写（REWRITE），不是新增行** —— 本期初稿把 `MiniMax M3.1 Flash` 开放权重另起一行（043 期已有该行），**已改为改写**，表体由 229 回到 228（**新增 5 / 改写 8**）。
- **044 期一条取料纪律**：**公告的真实 slug 必须从列表页 HTML 里「标题之后的最近一个 href」取** —— `openai.com/index/patch-the-planet/` 抓到的是 6 月旧文，真实 slug 是 `/index/coordinated-disclosure-of-critical-vulnerabilities/`。
- **044 期一条脚本纪律**：**脚注从「小表」改成「列表」后，按固定标记定位分节的取表逻辑会失效** → **改成「存在即截断、不存在则不截断」的条件式**（与 043 期同一根因的两副面孔）。

## 出刊流水线（顺序固定）

1. 读上期 md + `.workbuddy/data/frozen_items.md` + `.workbuddy/data/open_questions.md`
2. `check_frozen.py [src.md]`（🔴 高危会 exit 1；**高危可能只是措辞触发，改措辞不改守卫**；**必须先写库再跑**）
3. `extract_deadlines.py [src.md]` → `check_deadlines.py --today YYYY-MM-DD`
4. 写 md（增量 + 纠错）；第四章用 `gen_tableNNN.py` + `injectNNN.py` 生成注入

6. `build_source_hits.py` → `build_index.py` → `build_index_web.py` → `check_site_freshness.py`
   （**后两个每期必跑**，守卫须 ALL GREEN —— 008 期漏了 `build_index_web.py`，首页「更新至」卡住一整天）
7. git commit + push → **核实 sha** → **轮询 `pages/builds/latest` 到 `built`** → 带 `?t=<ts>` 抓线上页**逐字节比对**
   （Pages 构建有 1–2 分钟延迟，响应 `max-age=600`；**未带 token 时该 API 返回 404，可直接用逐字节比对替代且结论更强**）
   - ⚠️ **push 若报 `could not read Username … terminal prompts disabled`**：本机 `credential.helper=helper-selector` 是坏的。
     用 `git-credential-manager get` 取令牌 + **内联助手**推；**别改用 `helper=manager`——会卡死在 GCM 交互回退上**。详见 `ENGINEERING.md` §九。
   - ⚠️ **抓线上页之前必须先确认构建完成**（构建期间抓到的仍是上一期，011 期据此误判过）。
   - ⚠️ **`git add .workbuddy/data/` 会把 13 个历史备份文件一并暂存**（`.gitignore` 未覆盖这些命名），需逐条 `git reset` 掉
     （文件按用户长期约定不删，只是不进仓库）。
8. 写自动化记忆 + 当日日志

## 硬要求（短条目版 · 全文见 `ENGINEERING.md` §十·22）
