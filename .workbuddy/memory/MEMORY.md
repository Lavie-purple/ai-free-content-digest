## 展示规则（2026-09-16）
- **`AI信息源分级清单-T0-T4.md` 不对外展示**（内部台账，只用于路由与去重），照旧就地维护。
- 每次出刊**只 `present_files` 那一份日报**；**只有用户明确要求才展示台账**。
- **用户问「最简版 / 只看免费」时给 `quick.html`**（不是日报）：那条线只答四个字段，别拿日报顶。
- **三页是「一份刊物的三个视图」，不是三个独立网页**：日报 / `quick.html` / `standing.html` 顶部
  **同一位置都有三格切换器**（极速 / 完整 / 总账，当前格实心 + `aria-current`），首页三格都不高亮。
  组件在 `viewswitch.py` —— **改一处、三页同时变**；别在任一页单独加链接（047 期前就是这么散的，
  而且 `quick.html` 里「完整版日报」还错指到 `index.html` 首页）。**条数一律实算**，不许手写。
- **「三页同构」由 `check_views.py` 守，不靠记忆**（048 期立）：每期出刊后跑一次，
  它检查三格齐全、当前格唯一、「完整日报」指向最新一期、格内条数与源文件实算一致、样式在位；
  **任何一处不符 exit 1**。此前的失效形态是「页面照常打开、只是点进去是过期的」，肉眼看不出来。

## 出刊约定（全文见附卷 §十·22）
- **增量 + 纠错**，不重复往期已固化内容（先跑 `check_frozen.py`，🔴 高危 exit 1）。
- **十节固定结构**；**发布线与「免费内容」线是必备两章**。
- **刊头必标扫描截止时点**；**早间出刊必漏当天上午晚些时候的发布**。
- **同日双刊**：声明「正式刊 / 增补轮」+「两期不合并」+ 窗口起点 = 上期截止 + **美西/北京双向换算**；**隔日出刊换句式**。
- **短窗口（<2h）**：先核「窗口内确有落在线后的硬条目」再决定出刊/挂账 —— **只看窗口长度会误判**。
- **「计数」与「明细」同源生成**；**禁用「状态变更共 N 处」**；台账写「（N→M）」当场用表体行数验。
- **继承字段必须重算**：断言是「每行天数 == 截止日 − 基准日」，**不是「推进一天就 −1」**（040 期滚雪球）。
  ⚠️ `extract_deadlines` **不解析状态列里的倒计时文本** → 必须逐行手算复核。
- **流通量字段不得沿用上期**，定稿前重取；**升/降/同值都要记账**；**口径变过不可相减**。
- **「降档」一次写全三样**（模型/上下文/额度）；**按四条线分别过**；**图像·视频模型线**与**内容平台榜单线**
  是固定扫描位；**「定编扫描位」当期写成两维关键词表并实跑**。
- **第三方托管分发层扫描位（046 期立）**：**图像·视频模型线除厂商官网外，必须扫 `fal` / `Replicate` 类
  分发层的目录 API**（046 期 `Kling 4.0` 因 `fal.ai` 不在清单而跨期漏登）；**API 字段同一端点至少读两次**，
  批量同值字段（如 `fal` `reviewedAt` 40 模型同值）是目录级事实，不拆给单条目（避坑 203）。
- **OpenRouter 存档两层（046 期起）**：**`:free` 清单与全量目录**都存档入仓库（`tmp_or_free_*` /
  `tmp_or_all_*`），下期起两层都逐条 diff 并报增减名（045 期只存一层 → 046 期「全量 −1」定位不到）。
- **「开放」拆四层**（能用/能下载/能跑/能商用）；**多站点口径显式拆开写**（URL 主域名写进条目本身）。
- **第四章截止表一律脚本生成**（`gen_tableNNN.py` + `inject0NN.py`），**`<<<TABLE4>>>` 占位符必须为 0**；
  **换挡日不写可被解析的实日期**。
- **第四章脚注固定四段**：① 三态分布 ② A/B/C/D/E 实跑 ②-补 双口径三态 ③ 逐行 diff + 强制动作；
  **⚪ 与 C 的差额不是常数**（046 差 1 / 047 修订前差 3 / 修订后差 2）→ **必须逐条归因，不许写成「差 N 是正确口径」**；
  **两套口径数字必须从 `deadlines.csv` 实跑**。
- **第四章保留规则（047 期修订起 · 用户 2026-10-27 要求「过期太久要及时剔除」）**：
  **表体只留四类** —— ① 截止日不可解析的长期档（例外）② 未过期 ③ 已过期但未收口（状态非 ⚪：`crit` 必办 / `live` 仍写生效中）
  ④ 过期 ≤7 天；**过期 >7 天且已收口（⚪）的整行移出表体**，原文逐行归档到 `data/deadline_archive.md`（不截断/不改写/不删）。
  **固定步骤 `prune_table.py`**，接在 `gen_table` + `inject` 之后、`build_web` 之前；宽限期是参数（`--grace`，默认 7）。
  **移出 = 换位置不是删除**：表体 + 归档 = 全部历史；**移出前后必须对账**（⚪ 与 `over` 应同步减同一个数，否则说明误伤了亮色行）。
  **口径一变，与往期一律不可相减**，只报本期读数（047：239 → 185，−8.6% 字数）。
  **下一步（048 期已答应用户）**：**表体瘦身 MVP** —— 对 141 条「无截止日」长期档，表体只留「谁 / 到什么时候 / 要不要动手」
  一行结论 + 一句边界，长论证折进正文对应章节；目标第四章 112K → 30K 字量级。**只动第四章，不改事实**。

- **第四章结构改造（047 期修订二 · 2026-10-27 当天落地 · 用户「治标不治本」→「跟着建议做」）**：

  重新编号会同时打断「见三·3」「第四章」等全部历史引用）。标题带「（正文之后 · …）」。

## 内容口径纪律（030–045 期 · 全文见附卷 §十·25）
> 避坑编号 **138–207**（036: 158–161 / 037: 162–165 / 041–043: 179–192 / 044: 193–195 / 045: 196–199 / 046: 200–203 / 047: 204–207）；新立前查附卷。
- **信源计数先核台账**：「本期用过」≠「本期新增」，`git show HEAD` 逐行核首登期（045 期「新增 4 条」实为「新增 2 条+再次取用 2 条」；避坑 44 同族）。
- **三个脚本坑（045 期实修）**：`classify()` 误捕否定式规避措辞；`build_source_hits.py` 根别名须过 `norm()`、表格内 `>` 行重置 `in_tbl`；`verify_web.py` 的 `None` 守卫会捕真实字段值 → **改措辞不改守卫**。
- **md 引为 diff 锚点的存档要入公开仓库**（045 期 `tmp_or_free_2026-10-23.txt` 先例）。
- **多分发层「一手」是分层的一手（047 期立）**：同一模型在 `fal` / `Runware` 等分发层字段不同步时，**每个字段标来源层、禁止跨层拼规格**（`Kling 4.0`：`fal` 有定价无音频、`Runware` 有音频无定价）。
- **「页面上的日期」≠「条目日期」**（048 期新立避坑 208）：**三种渲染来源逐一甄别** —— 区块标题栏日期（`Anthropic` news 的「Latest news · October 27, 2026」，列表最新仍是 10/26）/ JSON-LD `dateModified`（`MiniMax`、`llm-stats`）/ 真实条目日期。**`dateModified` 永远不是发布日期**。
- **软 404 要分三层写**（048 期新立避坑 209）：**状态码（404）/ 正文（完整 SPA）/ 真实路径（`/kling-4`）** —— 三个都要记；**在软 404 页里读到的数字不能直接当成该模型的字段**（`$0.133` 属 `sync-3` 不属 `Kling 4.0`）。
- **换 URL 即换样本**（048 期新立避坑 210）：**字段计数只在「同一 URL + 同一取数方式」内可比**；**报计数必须把 URL 一并写出来**。
- **目录层 `created` 是「加入目录时间」不是「厂商发布时间」**（048 期新立避坑 211）：**窗口归属要看厂商一手页**，两者冲突时两个时间都写、各标来源。
- **相对日期不进绝对截止列**（「领取后 7 天内有效」）；**「官方只列 A/B/C 档」不写「D 不可用」**；**两个字段的大小关系也会翻转**（MiniMax `downloads` 详情/列表隔日反向）→ 只写「本期读数」。

   **必须在 `build_web` 之前，且移出后要重跑 `extract_deadlines.py` + `check_deadlines.py`，脚注数字随新读数重写**）
5. `build_web.py` → `verify_web.py`（**必须 ALL GREEN**）
   → **⚠️ 048 期实测：基准日与上期相同（「距今 N 天」按理不变）时，脚本仍抓出上期两行继承误差**

   「完整日报」指向最新一期、格里的条数与 `quick_items.csv` / `常驻权益总账.md` 实算一致，**必须 ALL GREEN**）
