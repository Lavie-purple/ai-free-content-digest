## 出刊约定

- 每期仍只做**增量 + 纠错**，不重复往期已固化内容。
- 报告结构固定：摘要（3 秒版）→ AI 免费内容发布 → 免费内容生成工具 → 常驻免费额度与 API → 限时活动与截止时间表 → 本期纠错清单 → 避坑提示（编号跨期连续）→ 按任务选型速查 → 信源体系更新 → 来源与核查说明。

- 交付前用脚本核对所有表格列数（逐行数 `|` 与分隔行比对），并检查避坑编号与前一期连续。
- 截止时间表要标 **生效中 / 换挡日 / 已结束** 三态，并优先复核「最近 3 天内的节点」。
- 涉及多站点口径的（如 WorkBuddy 国内站 vs 国际站、混元新老平台），必须**显式拆开写**，不能合并成一句。

## 网页版编译器与校验器（2026-09-17 建立）

- 编译器：`.workbuddy/build_web.py`。**常驻保留，不要删**。
- 用法（006 期起改为**命令行优先**，不再需要手改 `SRC`）：
  ```bash
  python .workbuddy/build_web.py "AI免费内容与权益速递-第006期-2026-09-17.md"
  ```
  不传参时回落到文件顶部的 `SRC`/`OUT` 常量（默认已指向最新一期）。issue 号、日期、主题行从 md 的 `#`/`>` 自动提取。
- 校验器：`.workbuddy/verify_web.py`。用法同上（不传参自动取工作区里日期最新的一期）。**每次编译后必须跑一遍，判定标准是 `VERDICT: ALL GREEN`。**
  四项：① 表格列数/行数逐表比对；② 全文片段保真（去掉标点后 ≥12 字符的片段必须能在 html 里找到）；③ 标签闭合/占位符/外部引用应为 0；④ 第四章状态格每格只应有一个色标且不留裸 U+FE0F。
  **注意**：保真比对必须**排除标题行**——html 里的章节号渲染成 `01/02…`，md 里是 `一/二…`，直接比会假报缺失。比对前统一"只保留中英文数字"再比，能绕开所有 markdown 标点/emoji 的对称性问题。
- 产物特征：单文件自包含（**0 外部引用**，约 98 KB）、离线可开、可直接打印 A4。
- 已实现能力（改这个脚本时别弄丢）：顶部导航 + 侧栏目录双高亮、全文检索（带命中计数与上下条跳转）、第四章按状态筛选（必办/今日换挡/生效中/口径存疑/已结束）、明暗主题（localStorage 记忆 + prefers-color-scheme 兜底）、阅读进度条、移动端目录抽屉、打印样式。
- **状态判定规则（006 期修订，别再改回去）**：**以状态格里最先出现的色标为准**。旧实现是 `⚠️` 无条件优先，会把"🟢 生效中……⚠️ 另有口径"这类行错判成"口径存疑"并从"生效中"筛选里漏掉。现在只有 `⚠️` 出现在任何颜色标之前才判 warn；`已结束` 文字仍强制 over。
  **同时必须摘干净色标**：`⚠️` 是 `U+26A0 + U+FE0F`，只 replace 基字符会在正文里留一个裸变体选择符（肉眼看不见、但确实渲染出来）。统一用 `ST_ANY_RE` 摘除。
- **设计规范**（详见 `~/.workbuddy/skills/frontend-design`）：暖纸质底 + 墨黑正文 + 单一信号色（赭红 #B23A1E）；标题字号用 `em` 相对单位，**不要用 `clamp(vw)`**；装饰性文字必须显式给 `opacity`/背景色，不能依赖 `z-index:-1`（会被 body 背景吞掉）。
