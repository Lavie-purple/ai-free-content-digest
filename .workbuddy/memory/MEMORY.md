## 展示规则
- **`AI信息源分级清单-T0-T4.md` 不对外展示**（内部台账，只用于路由与去重），照旧就地维护。
- 每次出刊**只 `present_files` 那一份日报**；**只有用户明确要求才展示台账**。
- **用户问「最简版 / 只看免费」时给 `quick.html`**（不是日报）：那条线只答四个字段。
- **三页是「一份刊物的三个视图」**：日报 / `quick.html` / `standing.html` 顶部同一位置都有三格切换器
  （极速 / 完整 / 总账，当前格实心 + `aria-current`），首页三格都不高亮。组件在 `viewswitch.py`
  —— **改一处、三页同时变**；**条数一律实算**。
- **「三页同构」由 `check_views.py` 守**（每期必跑）：三格齐全、当前格唯一、「完整日报」指向最新一期、
  格内条数与源文件实算一致；**任何一处不符 exit 1**。

## 出刊约定（全文见附卷 §十·22）
- **增量 + 纠错**，不重复往期已固化内容（先跑 `check_frozen.py`，🔴 高危 exit 1）。
- **十节固定结构**；**发布线与「免费内容」线是必备两章**。
- **刊头必标扫描截止时点**；**早间出刊必漏当天上午晚些时候的发布**。
- **同日双刊**：声明「正式刊 / 增补轮」+「两期不合并」+ 窗口起点 = 上期截止 + **美西/北京双向换算**；**隔日出刊换句式**。
- **短窗口（<2h）**：先核「窗口内确有落在线后的硬条目」再决定出刊/挂账。
- **「计数」与「明细」同源生成**；**禁用「状态变更共 N 处」**；台账写「（N→M）」当场用表体行数验。
- **继承字段必须重算**：断言是「每行天数 == 截止日 − 基准日」，**不是「推进一天就 −1」**。
  ⚠️ `extract_deadlines` **不解析状态列里的倒计时文本** → 必须逐行手算复核。
- **流通量字段不得沿用上期**，定稿前重取；**升/降/同值都要记账**；**口径变过不可相减**。
- **「降档」一次写全三样**（模型/上下文/额度）；**按四条线分别过**；**图像·视频模型线**与**内容平台榜单线**
  是固定扫描位；**「定编扫描位」当期写成两维关键词表并实跑**。
- **「开放」拆四层**（能用/能下载/能跑/能商用）；**多站点口径显式拆开写**（URL 主域名写进条目本身）。
- **第四章截止表一律脚本生成**（`gen_tableNNN.py` + `inject0NN.py`），**`<<<TABLE4>>>` 占位符必须为 0**。
- **第四章脚注固定四段**：① 三态分布 ② A/B/C/D/E 实跑 ②-补 双口径三态 ③ 逐行 diff + 强制动作；
  **⚪ 与 C 的差额不是常数** → **必须逐条归因**；**两套口径数字必须从 `deadlines.csv` 实跑**。
- **同仓库两种行尾**：`data/` CRLF、`memory/` LF。

## 第四章三条结构规则（全文见附卷 §十·29 · ③④⑤）
- **结构（047 修订二）**：`4.1 限时动作` + `4.2 常驻权益本期变更`；无变化的常驻权益移入根目录

- **表体瘦身（049 落地）**：状态列只留「谁 / 到什么时候 / 要不要动手」+ 一句边界；
  **被裁论证一字未删存 `details.html` + `data/table_full.md`**（后者是下期 `gen_table` 输入之一）。
  **流水线（049 定稿）**：`gen_table → inject → prune → split_ledger → 脚注 → slim(两轮) → 指针链接化 → extract/check → build/verify → lint --strict`。
  **⚠️ `slim` 必须在 `split_ledger` 之后，且必须跑两轮才收敛。**
- **保留规则（047 起）**：表体只留四类（长期档 / 未过期 / 已过期未收口 / 过期 ≤7 天）；

- **⚠️ `lint_table` 判据口径**：**R1 只看状态列且剔除链接指针；R3 只看状态列**（写进脚本注释）。
- **⚠️ 避坑条目必须写成行首「数字 + `.`」** —— 否则 `pit_range()` 抓不到编号。

## 050 期新增工程纪律（写脚本前必读）
- **① `prune_table.py --archive` 默认路径是相对路径** —— 在 `.workbuddy/` 下调用会写到 `.workbuddy/.workbuddy/data/`
  （**归档没进真档但表体已移出 = 事实丢失**）。**要么在仓库根调用，要么显式 `--archive "data/deadline_archive.md"`**。
- **② `split_ledger.py` 判「无截止日常驻档」靠截止列的**开头关键词**（`未公布`/`无结束日`/`无截止`/`未定`/`动态`/…）**，
  **不是语义判断** —— **写作格式是流水线的一部分，不是自由发挥**。
- **③ `gen_tableNNN.py` 的 REWRITE 键必须与源行文本**逐字符**一致**（写前先 `print` 源行原文）；
  **`NEW` 行末尾必须带 ` |`**。
- **④ 官方仓库图片可能是 git-LFS 指针** —— 真图走 `media.githubusercontent.com/media/…`。

## 内容口径纪律（030–050 期 · 全文见附卷 §十·29·⑥ 与 §十·25）
> 避坑编号 **138–222**（036:158–161 / 037:162–165 / 041–043:179–192 / 044:193–195 / 045:196–199 /
> 046:200–203 / 047:204–207 / 048:208–211 / 049:212–217 / **050:218–222**）；新立前查附卷。
- **信源计数先核台账**：「本期用过」≠「本期新增」，`git show HEAD` 逐行核首登期。
- **「页面上的日期」≠「条目日期」**（208）：区块标题栏日期 / JSON-LD `dateModified` / 真实条目日期逐一甄别；
  **`dateModified` 永远不是发布日期**；**标题栏日期会随出刊日逐日推进**。
- **软 404 分三层写**（209）：状态码 / 正文 / 真实路径；**软 404 页里的数字不能当该模型字段**。
- **换 URL 即换样本**（210）：**报计数必须把 URL 一并写出来**。
- **目录层 `created` 是「加入目录时间」不是「厂商发布时间」**（211）：**窗口归属看厂商一手页**。
- **「厂商侧未核到」是会过期的结论**（219）：**「未核到」只说明本报告还没去看**。
- **集合类指标必须总量与分项一起报**（220）；**状态矩阵要逐格对应**（221，弃用的只是那一格）；
  **图片里的数字 + 图例 + 脚注要一起读**（222）。
- **相对日期不进绝对截止列**；**「官方只列 A/B/C 档」不写「D 不可用」**；**字段大小关系会隔日翻转** → 只写「本期读数」。
- **多分发层「一手」是分层的一手** —— `fal`/`Runware` 字段不同步时**禁止跨层拼规格**。
- **第三方托管分发层是固定扫描位**：图像·视频模型线**必须扫 `fal`/`Replicate` 类目录 API**；**同一端点至少读两次**。
- **OpenRouter 存档两层**：`:free` + 全量都入仓库（`tmp_or_free_*` / `tmp_or_all_*`），下期起两层都逐条 diff。

## 出刊流水线（顺序固定）
1. 读上期 md + `data/frozen_items.md` + `data/open_questions.md`
2. `check_frozen.py`（🔴 高危 exit 1；**高危可能只是措辞触发，改措辞不改守卫**）
3. `extract_deadlines.py` → `check_deadlines.py --today YYYY-MM-DD`
4. 写 md（增量 + 纠错）；第四章用 `gen_tableNNN.py` + `inject0NN.py` 注入
   → **048 起 `gen_table` 输入 = 上期 4.1 表体 + 《常驻权益总账》全量表体**（4.2 已含在总账里、**不可重复加**）
   → **再跑 `prune_table.py --md <本期md> --today <基准日> --issue NNN`**（移出后**必须重跑 extract + check**）
5. `build_web.py` → `verify_web.py`（**必须 ALL GREEN**）
   → ⚠️ **「基准日没变」不是跳过重算的理由**，`gen_table` 的 diff 输出是唯一发现手段
5b. **`build_quick.py --check`** → 补齐 `data/quick_items.csv` → **`build_quick.py`**
   （**新增免费额度条目必须逐条补进去，量要写到具体数字，不许写「见官方页」**）
5c. 三页切换器由 `viewswitch.py` 统一渲染：`build_web.py`、`build_quick.py`、`build_index_web.py` 都 `import viewswitch`。
6. `build_source_hits.py` → `build_index.py` → `build_index_web.py` → `check_site_freshness.py` → **`check_views.py`**
   （**后三个每期必跑，必须 ALL GREEN**）
7. git commit + push → **核实 sha** → 带 `?t=<ts>` 抓线上页**逐字节比对**
   - ⚠️ push 报 `could not read Username`：`credential.helper=helper-selector` 坏 → `git-credential-manager get` 令牌 + 内联助手推。
   - ⚠️ **抓线上页前必须先确认构建完成**；⚠️ **`git add .workbuddy/data/` 会把历史备份一并暂存**，需逐条 `git reset`。
8. 写自动化记忆 + 当日日志
