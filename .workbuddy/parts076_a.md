**第二件：075 期说「页面未写免费额度」，这句话本期要升级成一句更硬的话。**

**第三件：把「开源」和「免费」这两件事分开标价，是这一代开源模型的共同动作。**

`Inkling 2 Mini` 权重是 `Apache-2.0`、`gated: false`、`~20GB`（075 期已核）；**API 侧第一天就挂了价**。这与 `Hy4 flash` 的路径**正好相反**：混元是**先在 `WorkBuddy` 内限免、再放权重**，`Thinking Machines` 是**先放权重、同一天把 API 按量卖**。**两条路都通向「免费的是权重，不是算力」** —— 读者要分清自己拿的是哪一个：**下载权重免费（自己出电费），调 API 收费（别人出电费）**。
